# Warung Simulator 3D (Lokal Indonesia)
Dibuat oleh: Aditia Hermawan

Game simulasi warung kelontong / Madura 3D ringan dengan fitur lengkap:
- barang-barang lokal Indonesia (Mi Instan, Kopi, Rokok, Minyak, Gas 3kg, Galon, Telur)
- Splash screen 5 detik dengan credit "Aditia Hermawan"
- Pencatatan Keuangan (Uang Kas, Pemasukan/Pendapatan Kotor, Pengeluaran/Kulakan)

## Cara Membuat APK via GitHub (Langsung dari HP Android):
1. Ekstrak file zip ini dan upload file `index.html` ke repository GitHub Anda (Public).
2. Aktifkan **GitHub Pages** di tab *Settings* -> *Pages* (Pilih Branch: main / root).
3. Salin link GitHub Pages yang didapat (misal: `https://username.github.io/warung-simulator/`).
4. Buka situs **[PWABuilder](https://www.pwabuilder.com/)** di browser HP.
5. Masukkan link GitHub Pages Anda lalu klik **Generate Android APK**.
6. Unduh file `.apk` dan install di HP Android Anda! Game bisa dimainkan 100% offline.
